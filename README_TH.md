# แดชบอร์ดผลการตรวจเชื้อ (Streamlit)

แอปนี้ช่วยดูผลการตรวจเชื้อแยกตามชนิดตัวอย่าง กรองตามทริป โครงการ จังหวัด และชนิดผลตรวจได้ทันทีจากแถบด้านซ้าย ไม่มีปุ่มรีเฟรช

หน้าแอปทั้งหน้าเป็นภาษาอังกฤษ (ชื่อเมนู ตัวกรอง กราฟ ตาราง และปุ่มดาวน์โหลด) คู่มือนี้เขียนเป็นภาษาไทยเพื่อให้อ่านตามขั้นตอนได้ง่าย

นิยามผลบวกใช้ชุดเดียวกับโน้ตบุ๊กเดิม เช่น titer ตั้งแต่ 1:50 ขึ้นไปถือว่าบวก, ค่า N ถือว่าลบ, ช่องว่าง / Waiting / no sample ไม่นับว่าตรวจ, และผล Suspected ไม่นับในตัวหารของร้อยละบวก

ร้อยละผลบวกแสดงในรูปแบบ `13.8% (778/5,620)` ทั้งในภาพรวม ตารางความชุก ตารางตามทริป ป้ายบนกราฟ และข้อความเมื่อชี้ที่แท่ง/จุด รวมถึงไฟล์ CSV ที่ดาวน์โหลดได้

---

## วิธีเปิดใช้งานฟรีบน Streamlit Community Cloud

ทำตามขั้นตอนนี้ได้จากเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมในคอมพิวเตอร์

### ขั้นที่ 1 สร้างที่เก็บไฟล์บน GitHub

1. เปิดบัญชี [GitHub](https://github.com) ถ้ายังไม่มี
2. กด **New repository** ตั้งชื่อเช่น `serology-dashboard`
3. เลือก **Private** ถ้ายังไม่ต้องการให้คนอื่นเห็นโค้ด (แอปที่เผยแพร่ยังอ่านข้อมูลได้ตามที่คุณตั้งในขั้นข้อมูล)
4. กด **Create repository**

### ขั้นที่ 2 อัปโหลดไฟล์แอป

ในหน้าคลังที่เพิ่งสร้าง กด **uploading an existing file** หรือ **Add file → Upload files** แล้วอัปโหลดไฟล์เหล่านี้จากโฟลเดอร์ `streamlit_dashboard`:

- `app.py`
- `analysis.py`
- `requirements.txt`
- `README_TH.md` (ถ้าต้องการ)

กด **Commit changes** เพื่อบันทึก

### ขั้นที่ 3 สร้างแอปบน Streamlit Cloud

1. เปิด [https://share.streamlit.io](https://share.streamlit.io) แล้วเข้าสู่ระบบด้วยบัญชี GitHub เดียวกัน
2. กด **New app** หรือ **Create app**
3. เลือกคลังที่อัปโหลดไว้ โฟลเดอร์หลัก และไฟล์หลักเป็น `app.py`
4. กด **Deploy**
5. รอสักครู่จนขึ้นหน้าแดชบอร์ด

ถ้าชีต Google แชร์แบบ **Anyone with the link can view** แอปจะดึงแท็บ `Data for analysis` ให้อัตโนมัติ  
ถ้าดึงไม่ได้ ให้ใช้ช่อง **Upload an Excel or CSV file** ที่แถบด้านซ้าย

### ขั้นที่ 4 ใช้ตัวกรอง

ตัวกรองที่แถบด้านซ้ายใช้ชื่อภาษาอังกฤษดังนี้:

- **Trip**, **Project** หรือ **Main project**, **Type of samples**, **Province**, และ **Tests** เลือกได้หลายค่า
- ถ้าไม่เลือกในช่องใด จะหมายถึงใช้ทุกค่าของช่องนั้น
- กราฟและตารางด้านขวาจะอัปเดตเอง ไม่ต้องกดรีเฟรช
- ร้อยละผลบวกอ่านเป็น `xx% (pos/tested)` เช่น `13.8% (778/5,620)` ทั้งในภาพรวม ตาราง และกราฟ
- สามารถดาวน์โหลดตารางสรุป (**Download summary table as CSV**), ตารางตามทริป และข้อมูลที่กรองแล้วเป็น CSV ได้ในหน้าแอป

## เรื่องความเป็นส่วนตัวของข้อมูล (สำคัญ)

- ถ้าแชร์ Google Sheet เป็น **Anyone with the link can view** คนที่มีลิงก์ชีต (หรืออาจเดาลิงก์ได้) จะอ่านข้อมูลได้ รวมถึงแอปที่ดึงชีตนี้
- ถ้าข้อมูลมีรายละเอียดอ่อนไหว **แนะนำให้อัปโหลดไฟล์ในแอปแทน** และไม่เปิดชีตเป็นสาธารณะ
- บน Streamlit Cloud ควรตั้งแอปเป็นแบบจำกัดผู้ใช้ (private / invited viewers) ถ้าข้อมูลไม่ใช่ข้อมูลสาธารณะ
- ไฟล์ที่อัปโหลดในเซสชันจะใช้ระหว่างเปิดหน้าแอป ไม่ได้ถูกบันทึกลงคลัง GitHub โดยอัตโนมัติ

## วิธีรันในเครื่องตัวเอง (ถ้ามี Python)

ในโฟลเดอร์ `streamlit_dashboard` เปิดเทอร์มินัลแล้วพิมพ์:

```bash
pip install -r requirements.txt
streamlit run app.py
```

เบราว์เซอร์จะเปิดหน้าแอปขึ้นมา ถ้าชีตไม่เป็นสาธารณะ ให้ใช้ช่อง **Upload an Excel or CSV file** ที่แถบด้านซ้าย

---

## วิธีลองอย่างเร็วใน Google Colab (ทางเลือก)

วิธีบน Cloud ข้างต้นใช้ง่ายกว่าสำหรับผู้ที่ไม่เขียนโค้ด แต่ถ้าต้องการลองใน Colab:

1. อัปโหลดโฟลเดอร์ `streamlit_dashboard` เข้า Colab (หรืออัปโหลดไฟล์ `app.py`, `analysis.py`, `requirements.txt`)
2. รันช่องนี้:

```python
!pip install -q -r requirements.txt
!streamlit run app.py --server.port 8501 --server.headless true --server.enableCORS false --server.enableXsrfProtection false &
import time; time.sleep(5)
!npx --yes localtunnel --port 8501
```

3. เปิดลิงก์ที่ `localtunnel` แสดง ถ้ามีหน้าต่างถามรหัส ให้ใส่เลข IP ที่ Colab แสดงไว้ในผลลัพธ์ของ localtunnel
4. ถ้าไม่ดึงชีตได้ ให้อัปโหลดไฟล์ Excel ในหน้าแอป

หาก Colab หรือ localtunnel ใช้ยาก ให้กลับไปใช้ Streamlit Community Cloud ตามขั้นตอนด้านบน
